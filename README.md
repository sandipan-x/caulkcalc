# CaulkCalc

Caulk tubes needed from joint length and bead size, with waste and cost.

## Features
- Bead-size selector (1/8in-1/2in) with true coverage math
- Room-by-room joint list (windows, doors, baseboards, tub/shower)
- Waste factor + cost estimator by tube size
